# ⚡ Spinta · Studio video

App (PWA) di EssentialApp per analizzare, migliorare e pubblicare i video TikTok.

**Apri l'app:** https://essentialapp-2026.github.io/Spinta/spinta.html

- `spinta.html` – l'app (un solo file)
- `spinta-regole.json` – regole dell'algoritmo e tendenze, aggiornate ogni lunedì in automatico
- `manifest.json`, `sw.js`, `icon-*.png` – installazione e funzionamento offline
